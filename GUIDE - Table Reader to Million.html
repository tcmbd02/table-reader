From time cards to Million Payroll

Bahasa Melayu

How to turn scanned time cards into a file with Table Reader and import it into Million Payroll. Tested on 9 October 2026 with two client companies (6 employees): every figure arrived in Million exactly as in the file.

  1. A. ReadAdd the scans to Table Reader and check the yellow cells.
  2. B. PayrollPick the month, add the employees, type their Employee No.
  3. C. FileChoose the company and download the Million file (.xls).
  4. D. MillionBack up, make sure the employees are in the month, import.
  5. E. CheckOpen one or two employees in Million and compare.
The three things that must be true before an import works
  1. The employee exists in Million (Employee tab > Employee).
  2. The Employee No. is the same in Table Reader and in Million, character for character (MJ(1) is not MJ1).
  3. The employee is in that month's payroll in Million (Transaction > Payroll > the month > Edit).
If one of them is missing, Million skips that employee without any warning, or says that no record was updated.

A. Read the time cards in Table Reader

  1. Open Table Reader. If it asks, press Sign in (top right) and sign in to Claude.
  2. Drop the scans or photos (PDF, JPG or PNG) on the page, and choose the company they belong to.
  3. Wait until each file shows Finished.
  4. Open each file and check every yellow cell against the picture. Type the right value, or leave it empty if it really cannot be read.

Table Reader never guesses. A day whose date, hours or IN/OUT time is still yellow is left out of the payroll and listed under "Please check".

B. Prepare the payroll in Table Reader

B0. Give Table Reader Million's employee list (once, and again after adding employees in Million)

  1. In Million: Employee tab > Employee, Alt+P (Print).
  2. Click Employment Listing (or leave Payroll Information selected: both work), Alt+P (Print), then Excel.
  3. Choose File, Alt+O (OK). Million does not ask where to save: it writes rptempepmlist.xls (Payroll Information: rptemppsnlist.xls) into its company folder (on this laptop C:\million\Payroll\mycompany).
  4. In Table Reader: Payroll > Import employee list from Million, and choose that file.

Table Reader keeps only the Employee No. and the name. From then on every Employee No. box offers Million's list, and before the Million file is made Table Reader checks each number and name against it.

B1. The month and the employees

  1. Press Payroll (top bar).
  2. 1. Month and days: choose the month and year. Click each public holiday until it is yellow (white = working day, grey = rest day).
  3. Check the two rules beside the month:
    • Normal hours in a working day (overtime starts after this).
    • Break taken off IN/OUT time cards (1 hour unless you change it).
  4. 2. Employees and their time cards: press Add employees from files. One employee is added for each worker, with their cards ticked.
  5. Type each Employee No. exactly as in Million, or pick it from the list the box offers (B0). When exactly one name in Million's list fits the employee, a button Use … (… in Million) appears beside the box: one click fills it in. It is remembered for the following months.
  6. 3. Results: go through the employees. Complete is ready. For Needs checking, read "Please check" and fix the cells in the document, add the missing card, or type the figure yourself.

C. Download the Million file

Fewest clicks: one file for the whole month. Press Make the month's Million file (all companies). Table Reader makes one file, Payroll 2026-09 (Million).xls, with every employee who is ready, and lists everyone else company by company with the reason (no Employee No., not in Million, another name in Million, still to be checked). Import that one file in Million (D4): one import instead of one per company. Fix what is listed, press the button again, and import the new file again; importing again is harmless.

To make the file of one company only (for example to include an employee who is still marked INCOMPLETE):

  1. Choose the company in the chooser at the top, so the file holds only that company's employees.
  2. Press Download Million file (.xls).
  3. The file is called Payroll 2026-09 COMPANY (Million).xls. A copy is always kept in Documents > Table Reader > payroll.

D. Import into Million Payroll

Million's buttons often ignore the mouse. Use the keyboard: Alt+S Save, Alt+C Close, Alt+E Edit, Alt+A Add, Alt+Y Yes, Alt+O OK. The first click on a window only wakes it up.

D1. Back up first

  1. Close any open Million window, then click Backup Database on the left.
  2. Alt+O (OK), Alt+Y (Yes). Wait for "Backup database complete".

Each backup replaces C:\million\Payroll\mycompany\mycompany.bak. To keep an older one, copy it to another name first.

D2. Is every employee in Million?

  1. Employee tab > Employee. Look for each Employee No. of your file.
  2. Missing? Press Alt+A (Add), type the Employee No. and the Name, then Alt+S (Save). Million saves with just these two. Fill in the rest (I/C No., gender, Basic Rate, EPF, SOCSO…) before a real payroll is processed.

D3. Is every employee in the month's payroll?

  1. Transaction tab > Payroll. Click the month, then Alt+E (Edit). The list shows who is in that month.
  2. Someone missing? Press Alt+A (Add). The list shows the employees who are not in the month yet.
  3. Tick them with the keyboard: click the small box at the end of the row (this only selects it), then press Space. Use ↓ and Space for the next rows.
  4. Alt+S (Save), then Alt+Y (Yes). They now appear in the month with status New.
A month that is already Processed has no Add button: nobody can be added and an import updates nothing. Use a month that is not processed yet, or ask before un-processing a month.

D4. Import the file

  1. Close the payroll windows (Alt+C).
  2. Menu System > Administrative Tools, click 9. Import Data from External File, Alt+O (OK).
    Be careful to click line 9, not "5. Clear All Records".
  3. Click the month the figures are for, then Alt+I (Import).
  4. In the Open window set Files of type to Excel 97-2003 (*.xls). It starts on "Text (*.txt)" every time, and the folder looks empty until you change it.
  5. Go to Documents > Table Reader > payroll, choose the file, press OK.
  6. "Are you sure you want to update?": Alt+Y (Yes).
  7. Wait for "Update complete.", press Enter, then Alt+C to close.
"Update complete" appears even when an employee was skipped. Always do step E.

E. Check the result in Million

  1. Transaction tab > Payroll, click the month, Alt+E.
  2. Click an employee, Alt+E. Compare Working Days, Public Holiday, Days Worked and the Overtime table with Table Reader's Results (allowances and deductions are on the Allowance & Deduction tab).
  3. Next (Alt+N) moves to the following employee. Leave with Alt+C (Close), not Save.
What the test showed. A new employee starts with Working Days 26, Public Holiday 0, Days Worked 26. After the import the employees of the file showed the file's figures (for example 25 / 1 / 21), and employees who were not in the file were left untouched.

Good to know

  • The import replaces. Every figure the file has a column for is written into Million, zeros included. An allowance or deduction typed by hand in Million before the import is set back to 0 unless it is also in Table Reader. Import first, then type the extras, or type them in Table Reader.
  • Employees who are not in the file are not changed, so companies can be imported one after another into the same month.
  • Importing the same file again is harmless: it writes the same figures.
  • Use only the .xls file from "Download Million file". Million's CSV import ignores the column settings.
  • Basic Rate, director fee and back pay are not on a time card: keep them in Million.
  • The columns of the file follow Million's File Format Setting (inside the Import window). If someone changes that setting, the file no longer fits: tell whoever looks after Table Reader.
